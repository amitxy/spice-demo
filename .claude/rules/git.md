# Git conventions

## Commit format
Follow Conventional Commits: `<type>(<scope>): <description>`

- Subject line max 50 characters, imperative mood
- Types: `feat` `fix` `docs` `style` `refactor` `test` `chore`
- Example: `feat(auth): add login validation`

## Hard rules
- No AI attribution of any kind — no "Co-authored-by Claude", no Anthropic mention, no AI signatures
- Write commits exactly as a human developer would
